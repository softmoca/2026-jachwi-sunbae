# 저렴한 한 끼 찾기 기능 명세

- 상태: 검토용 초안 v0.1 / 작성일: 2026-10-29 / 대상: 웹 프론트엔드

## 1. 목적과 범위

사용자는 홈의 `오늘 한 끼, 저렴하게` 카드에서 주변 착한가격업소, 편의점 행사상품, 배달 할인정보를 확인한다.

식당, 편의점, 배달 탭, 지도와 목록, 상세 화면, 필터, 위치 검색, 뒤로가기, 로딩, 오류, 빈 결과를 다룬다. 데이터 수집이나 적재를 새로 수행하지 않고 기존 인증과 조회 API를 사용한다. 주문·결제, 매장별 재고 조회, 네이티브 앱 변경은 범위에 포함하지 않는다.

착한가격업소 데이터의 적재·원본 보존 정책은 [지도 명세](map.md#34-착한가격업소), 편의점 수집·저장·조회 정책은 [편의점 행사상품 명세](convenience-store-promotions.md)를 따른다.

## 2. 요구사항

- `REQ-MEAL-001`: 모바일과 데스크톱 홈에서 저렴한 한 끼의 식당 탭으로 진입하고 식당, 편의점, 배달 중 하나를 선택한다.
- `REQ-MEAL-002`: 식당 탭에서 매물 등록 없이 기준 위치 주변 2km의 착한가격업소를 지도와 목록으로 확인한다.
- `REQ-MEAL-003`: 주소 검색, 명시적 현재 위치 요청, 지도 이동 후 재검색으로 식당 조회 위치를 바꾼다.
- `REQ-MEAL-004`: 업소의 원본 업종·주소·메뉴와 가격·직선거리·데이터 기준일을 확인하고 전화 또는 외부 길찾기를 실행한다.
- `REQ-MEAL-005`: 이마트24·세븐일레븐 행사상품을 브랜드·행사 유형별로 확인하고 상품 상세와 공식 출처를 연다.
- `REQ-MEAL-006`: 배민·쿠팡이츠 할인정보를 플랫폼별로 확인하고 할인금액·최소 주문금액·기간·조건·마지막 확인 시각을 조회한다.
- `REQ-MEAL-007`: 탭을 왕복해도 탐색 상태를 유지하고, 상세 닫기와 브라우저 뒤로가기로 기존 목록에 돌아간다.
- `REQ-MEAL-008`: 로딩, 조회 오류, 빈 결과와 누락 정보를 구분하고 실패한 조회를 다시 시도한다.

## 3. 정책

### 3.1. 진입과 상태 유지

| 주소                           | 화면                                     |
| ------------------------------ | ---------------------------------------- |
| `/cheap-meals`                 | 식당 (기본 탭): 착한가격업소 지도와 목록 |
| `/cheap-meals?tab=restaurant`  | 식당: 착한가격업소 지도·목록             |
| `/cheap-meals?tab=convenience` | 편의점: 브랜드별 행사상품                |
| `/cheap-meals?tab=delivery`    | 배달: 플랫폼별 할인정보                  |

- `POL-MEAL-001`: 탭은 식당, 편의점, 배달 세 가지이고 홈에서는 식당 탭으로 진입한다. `tab`이 없거나 지원하지 않는 값 (예전 주소의 `?tab=all` 포함)이면 식당 탭을 표시한다. 편의점과 배달 데이터는 미리 조회하지 않고 해당 탭을 선택할 때 조회를 활성화한다. 식당 탭도 위치는 버튼을 누를 때만 요청한다 (`POL-MEAL-005`). 데스크톱은 왼쪽 13rem 사이드바에 `저렴한 한 끼` 제목과 세로 탭 (위/아래 방향키로 전환)을 두고 오른쪽에 내용을 둔다. 모바일은 위쪽에 세 칸 가로 탭을 둔다.
- `POL-MEAL-002`: 페이지 안에서 탭을 왕복하면 필터·목록 스크롤·더 보기 개수·식당 조회 위치와 확대율을 유지한다. 새로고침이나 페이지 재진입 시에는 URL의 카테고리를 사용하고 메모리에 둔 탐색 상태는 초기화한다.
- `POL-MEAL-003`: 기존 익명 로그인과 인증 갱신 흐름을 사용한다. 인증 오류를 빈 목록이나 임의의 샘플 데이터로 바꾸지 않는다.

### 3.2. 식당

- `POL-MEAL-004`: 최초 조회 위치는 우테코 판교 사옥이다. 조회 반경은 항상 2km이며 500m·1km·2km 선택 버튼은 제공하지 않는다. 주소 검색·현재 위치·지도 재검색에도 같은 반경을 적용한다. API는 다른 지원 반경도 받지만 이 화면은 `radius=2000`으로 요청한다.
- `POL-MEAL-005`: 현재 위치는 사용자가 버튼을 누를 때만 요청한다. 권한 거부·조회 실패·국내 범위 밖 좌표는 안내하고 기존 조회 위치를 유지한다. 사용자는 다시 요청하거나 주소 검색으로 위치를 선택할 수 있다. 주소 검색을 닫거나 탭을 떠난 뒤 도착한 위치 응답은 적용하지 않는다.
- `POL-MEAL-006`: 주소 검색 결과를 선택하면 그 좌표를 조회 기준과 지도 중심으로 사용한다. 지도를 끌어 옮기면 이동이 멈추고(idle) 400ms 뒤 지도 중심을 조회 기준으로 바꿔 다시 조회한다. 연달아 옮기면 마지막으로 멈춘 자리만 조회하고, 가게나 주소를 골라 지도가 옮겨 간 경우는 다시 조회하지 않는다. 새 결과가 올 때까지 이전 목록과 마커를 그대로 둔다.
- `POL-MEAL-007`: 반경 안의 업소를 개수 제한 없이 가까운 순으로 보여준다. 음식점 외 업종도 포함하며 업종과 메뉴 가격 문자열을 원문대로 표시한다. 거리는 기준 위치에서의 직선거리이며 가격은 등록 당시 정보임을 안내한다.
- `POL-MEAL-008`: 마커나 목록 항목을 선택하면 업소 상세를 연다. 전화번호가 있으면 전화 링크를 제공하고 없으면 미등록 상태를 표시한다. 외부 길찾기 링크를 제공하며 목록·상세에 데이터 출처와 제공된 기준일을 표시한다. 메뉴·가격·기준일이 없으면 누락 상태를 유지한다.

### 3.3. 편의점

- `POL-MEAL-009`: 기본 브랜드는 이마트24이며 세븐일레븐으로 전환할 수 있다. 행사 유형은 전체·1+1·2+1·할인·기타 행사이고 기본값은 전체다. 기타 행사는 3+1과 골라담기를 포함한다. 브랜드별 전체 목록을 조회한 뒤 행사 유형을 화면에서 필터링한다.
- `POL-MEAL-010`: 목록은 처음 24개를 표시하고 더 보기마다 24개씩 늘린다. 브랜드나 행사 유형을 바꾸면 표시 개수를 24개로 초기화한다. 상품의 판매가격을 그대로 표시하고 행사 수량으로 나눠 단가나 절약 금액을 계산하지 않는다.
- `POL-MEAL-011`: 상품 상세에서 브랜드·상품명·이미지·판매가격·행사 유형·상품 카테고리와 공식 출처를 확인한다. `UNKNOWN`은 `카테고리 정보 없음`으로 표시하고 목록에서 제외하거나 상품명으로 분류하지 않는다. 이미지 로딩 실패는 대체 표시로 처리한다.
- `POL-MEAL-012`: 목록에 마지막 수집 시각을 한국 시간으로 표시하고 공식 행사 페이지 링크를 제공한다. 유효한 HTTPS 출처 URL이 없으면 링크를 만들지 않는다. 매장별 행사 적용과 재고가 다를 수 있음을 안내한다.

### 3.4. 배달

- `POL-MEAL-013`: 기본 필터는 전체이며 배민·쿠팡이츠로 전환할 수 있다. 서버가 반환한 할인정보를 플랫폼별로 필터링한다. 처음 24개를 표시하고 더 보기마다 24개씩 늘리며 플랫폼 변경 시 표시 개수를 24개로 초기화한다.
- `POL-MEAL-014`: 목록·상세에 할인금액과 최소 주문금액·적용 조건을 표시하고, 상세에서 시작일·종료일·마지막 확인 시각을 추가로 제공한다. 누락된 최소 주문금액·기간·조건은 `정보 없음`으로 표시하고 마지막 확인 시각은 한국 시간으로 표시한다.
- `POL-MEAL-015`: 배달비·중복 할인·매장별 조건에 따라 실제 적용 여부가 달라짐을 안내한다. 최종 결제금액을 추정하거나 응답에 없는 주문 링크를 생성하지 않는다.

### 3.5. 상세 닫기와 접근성

- `POL-MEAL-016`: 상품·배달 상세는 닫기·Escape·브라우저 뒤로가기로 닫고 기존 탭과 목록 상태로 돌아간다. 상품·배달·주소 검색 모달은 배경 스크롤을 잠그고 초점을 내부에 제한하며, 닫으면 기존 조작 요소가 남아 있는 경우 초점을 복원한다.
- `POL-MEAL-017`: 업소 상세와 주소 검색은 하나의 탐색 이력을 사용한다. 열린 상태에서 다른 마커를 누르거나 주소 검색으로 전환해도 이력이 쌓이지 않는다. 닫기·뒤로가기 또는 주소 선택 한 번으로 목록으로 돌아가며, 상세·검색 URL로 직접 진입한 경우에는 현재 식당 탭을 유지하며 닫는다.
- `POL-MEAL-018`: 식당 목록·상세 시트는 지도를 함께 조작할 수 있는 비모달 시트다. 목록을 닫은 뒤 `가게 목록 보기`로 다시 열 수 있고 시트의 끌개와 키보드 위·아래 방향키로 높이를 바꿀 수 있다. 탭은 키보드로 전환할 수 있으며 작은 화면과 Safe Area에서도 상세 내용을 스크롤할 수 있다.

### 3.6. 조회 상태와 실패 처리

- `POL-MEAL-019`: 각 카테고리에 로딩과 조회 오류를 표시하고 오류에는 다시 시도를 제공한다. 편의점은 미수집 (`count=0`, `collectedAt=null`), 수집 완료 후 0건, 행사 필터 결과 0건을 구분한다. 식당 0건은 다른 동네 찾기를 제공하고 배달 0건은 현재 유효한 할인정보가 없음을 표시한다.
- `POL-MEAL-020`: 지도 SDK 인증 실패는 지도 영역에서 안내하고 업소 목록과 다른 카테고리는 계속 사용할 수 있게 한다. 지도 다시 시도는 페이지를 새로고침하므로 메모리에 둔 필터와 탐색 상태는 초기화한다.

| AC-MEAL-005 | 주소 검색에서 위치 요청을 시작하고 닫기·뒤로가기 또는 다른 탭 이동 후 응답을 완료한다. | 늦은 응답으로 지역이 바뀌지 않으며 식당에 돌아오면 위치 버튼을 다시 사용할 수 있다.                                      |
| AC-MEAL-006 | 지도를 끌어 옮긴다.                                                                    | 버튼 없이 이동이 멈춘 자리의 2km 업소 목록을 표시하고 기준 위치를 `지도에서 선택한 위치`로 바꾼다.                       |
| AC-MEAL-007 | 음식점 외 업종이나 문자열 가격을 가진 업소의 마커·목록을 선택한다.                     | 원본 업종과 가격, 직선거리, 제공된 기준일을 상세에서 확인한다. 전화번호가 없는 경우 전화 링크는 없다.                    |
| AC-MEAL-008 | 같은 업소 마커를 반복 선택하거나 상세에서 주소 검색으로 전환한 뒤 닫는다.              | 한 번 닫기로 목록으로 돌아간다. 새 주소를 선택한 뒤 뒤로가기 해도 이전 상세가 다시 열리지 않는다.                        |
| AC-MEAL-009 | 업소 상세 또는 주소 검색 URL로 직접 진입한 뒤 닫는다.                                  | 다른 페이지로 이탈하지 않고 식당 목록을 유지한다.                                                                        |
| AC-MEAL-010 | 편의점 브랜드와 행사 필터를 바꾸고 기타 행사를 선택한다.                               | 해당 브랜드·유형의 상품만 표시하고 기타 행사에는 3+1·골라담기가 포함된다. `UNKNOWN` 상품도 상세까지 표시한다.            |
| AC-MEAL-011 | 편의점·배달에서 더 보기를 누르고 다른 탭을 왕복한 뒤 필터를 바꾼다.                    | 더 보기마다 24개씩 늘고 탭 왕복 시 필터·표시 개수·스크롤이 유지된다. 필터를 바꾸면 표시 개수는 24개로 돌아간다.          |
| AC-MEAL-012 | 상품 이미지가 실패하거나 편의점 수집·상품·필터 결과가 비어 있다.                       | 이미지 대체 표시와 각각의 빈 상태를 구분하며 가격을 계산하거나 샘플 상품을 채우지 않는다.                                |
| AC-MEAL-013 | 배달 플랫폼을 선택하고 최소 주문금액·기간·조건이 없는 혜택 상세를 연다.                | 선택한 플랫폼의 혜택을 표시하고 누락값은 `정보 없음`으로 유지한다. 최종 결제금액과 주문 링크는 생성하지 않는다.          |
| AC-MEAL-014 | 상품·배달 상세를 닫기·Escape·브라우저 뒤로가기로 닫는다.                               | 상세만 한 번 닫히고 기존 탭과 목록 상태가 유지된다. 모달 스크롤 잠금이 해제되고 가능한 경우 이전 요소로 초점이 돌아간다. |
| AC-MEAL-015 | API 오류 후 다시 시도하거나 지도 SDK 인증 실패를 발생시킨다.                           | API는 오류와 빈 결과를 구분하고 재시도로 복구한다. 지도 인증 실패에도 업소 목록과 탭 탐색을 계속 사용할 수 있다.         |
