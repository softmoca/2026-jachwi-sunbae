# 기능 명세

이 디렉터리의 문서는 제품 동작 기준입니다. 각 명세에 목적과 범위, 요구사항, 정책과 인수 기준을 기록합니다.

| 명세                                                         | 책임                                                                                |
| ------------------------------------------------------------ | ----------------------------------------------------------------------------------- |
| [인증](authentication.md)                                    | 익명 회원 자동 로그인, 로그인 유지, 회원 탈퇴와 접근 권한                              |
| [매물](property.md)                                          | 매물 CRUD, 기본·부가 정보, 자유 메모와 정렬                                         |
| [사진](photo.md)                                             | 업로드, 대표 사진과 논리 삭제                                                       |
| [체크리스트](checklist.md)                                   | 시스템·사용자·매물 적용 체크리스트와 진행 현황                                      |
| [지도](map.md)                                               | 위치 선택, 매물 핀과 주변 분석                                                      |
| [저렴한 한 끼](cheap-meals.md)                               | 홈 진입, 주변 2km 착한가격업소, 편의점 행사상품·배달 할인 화면과 탐색 동작          |
| [편의점 행사상품 수집·조회](convenience-store-promotions.md) | 브랜드별 행사상품 수집·저장과 조회 API 정책                                         |
| [거리 메모](street-memo.md)                                  | 지도 위 동네 정보의 익명 공유, 작성·조회·본인 삭제와 기능·비기능 요구사항           |
| [매물 비교·PDF](compare.md)                                  | 매물 선택, 선택 순서와 비교 PDF 구성                                                |
| [생활권 탐색](commute-area.md)                               | 목적지 기준 통근 가능 동네 탐색과 GTFS 노선망 적재                                  |
| [생활권 탐색 GTFS 데이터](commute-area-gtfs.md)              | GTFS CSV 구조, 파싱 흐름과 단계별 적재 건수                                         |
| [날씨](weather.md)                                           | 전국 예보 수집, 현재 위치 날씨 조회, 정기 생활 날씨 알림                            |
| [알림](notifications.md)                                     | 날씨·배달 할인 공통 알림 수신 설정, 배달 할인 알림 발송 조건과 스케줄               |
| [소형 주택 월세 참고 정보](rental-transactions.md)           | 후속 기능: 추천 지역의 최근 월세 사례, 제공 범위·표시 기준·빈 목록과 조회 실패 처리 |

요구사항 ID는 `REQ-<도메인>-NNN`, 정책 ID는 `POL-<도메인>-NNN`, 인수 기준 ID는 `AC-<도메인>-NNN`을 사용합니다.
