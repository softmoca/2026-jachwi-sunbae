# 사용 방법과 비로그인 동네 탐색

## 로컬 확인

작업 브랜치: `feat/370-landing-exploration-login`. 기존 서비스 화면과 별개로 공개 탐색 화면을 제공한다.

- `/`: 첫 진입부터 홈을 보여 준다. 자동 로그인(Refresh 쿠키로 복원하거나 새 익명 회원 생성)을 기다리는 동안에도 홈을 바로 그린다.
- `/landing`: 광고로 들어오는 사람을 위한 랜딩. 로그인 없이 보고 자동 로그인을 일으키지 않는다. 서비스 안에서는 홈 푸터의 `자취선배 소개` 링크로 들어온다. 구성은 아래 [랜딩](#랜딩)을 따른다.
- `/guide`: 사용 방법. 로그인 없이 볼 수 있고 자동 로그인을 일으키지 않는다. 홈의 `사용방법 알아보기` 카드와 마이 메뉴에서 들어온다. 홈 푸터에는 카드와 겹쳐 두지 않는다. 짧은 익명 기록 안내 뒤에 시나리오 네 개(동네 찾기, 거리 메모 남기기, 매물 추가, 체크리스트)를 실제 화면 녹화 영상과 함께 보여 준다. 시나리오마다 짧은 순서 세 줄과 그 기능(`/neighborhoods`, `/properties`, `/properties?view=map`, `/checklists`)으로 가는 링크를 둔다. 넓은 화면에서는 설명을 왼쪽, 영상을 오른쪽에 두고, 데스크탑(1024px 이상)은 시나리오를 두 열 카드로 놓는다. 영상은 화면에 보일 때만 반복 재생하고, 재생 전과 움직임 줄이기 설정에서는 마지막 장면을 보여 준다. 앱 설치 안내와 로그인 링크는 두지 않는다.
- `/about`: 예전 서비스 소개 주소. `/guide`로 이동한다.
- `/explore`: 하단 서비스 탭 없는 공개 지도. 통근 시간과 월세 시세를 한 지도에서 함께 본다. 검색 또는 지도 선택 후 통근·환승 조건으로 조회하고, 결과 동네마다 월세 시세를 보여 주며 월세 상한으로 화면에서 거른다. 기준을 고르던 예전 주소 `/explore/commute`, `/explore/price`는 `/explore`로 보낸다.
- 결과의 `이 동네에서 본 방 기록하기`: 예전 로그인 주소(`/login`)로 이동하고, 그 주소는 자동 로그인 뒤 홈으로 이어진다. 등록 폼으로 바로 보내지 않는다.
- 동네 상세의 `현재 매물 확인하기` 카드(다방 로고 · `다방에서 {동네} 원·투룸 보기`): 선택한 동네의 중심 좌표로 다방 웹 지도 `https://www.dabangapp.com/map/onetwo?m_lat&m_lng&m_zoom=15`를 새 탭에 연다. 데스크톱 폭(1024px) 미만이면 `/mobile/map/onetwo`로 바로 연다. 다방 서버의 모바일 자동 이동은 `m_zoom` 뒤에 `}`를 붙여 줌을 무시하기 때문이다. 공개 탐색과 서비스 탐색 모두 표시하고 매물 데이터는 가져오지 않는다. 다방이 문서화한 딥링크가 아니라 다방 코드가 만드는 주소 형식을 따른 것이므로, 형식이 바뀌면 좌표 없이 다방 지도만 열릴 수 있다. 월세 상한은 넘기지 않는다.
- 동네 상세의 `정류장·공인중개사 보기` 카드: 선택한 동네의 중심 좌표로 동네 주변 분석(공개 탐색은 `/explore/nearby`, 서비스 탐색은 `/neighborhoods/nearby`)을 연다. 매물 주변 분석과 같은 반경·카테고리 지도를 쓰며 교통·중개업소를 먼저 표시한다. 좌표·동네 이름·돌아갈 경로는 쿼리로 넘기고, 돌아갈 경로는 서비스 안 주소만 허용한다. 행정동 코드를 좌표로 바꾸는 API가 없어 결과 응답의 동네 중심 좌표를 그대로 쓴다. 지도를 가리지 않도록 결과 지도 위에는 두 카드를 표시하지 않는다.
- 통근 결과에서 동네를 골라도 그 동네의 출발 정류장만 따로 마커로 찍지는 않는다(데스크탑은 동네 요약의 출발 정류장 목록에서 고른다). 대신 결과 지도에서 동네를 고르거나 가까이 확대하면 화면 안의 버스정류장과 공인중개사를 모두 마커로 보여 주고, 누르면 이름·연락처 카드를 띄운다.

프론트엔드에서 `PORT=3000 USE_REAL_COMMUTE_API=false POSTHOG_PROJECT_TOKEN='' npm run dev:mock`으로 실행한다. 로컬 시안은 MSW 응답이며 외부 PostHog에 전송하지 않는다. 기존 `/neighborhoods` 경로는 유지한다.

최신 develop에서 공개된 통근·월세·지도 주소 API를 사용한다. 인증을 우회하거나 가짜 토큰을 생성하지 않는다.

기록 버튼은 예전 로그인 주소(`/login`)로 이동하고, 그 주소는 홈으로 넘어가며 자동 로그인(`POST /api/auth/login`)한다. MSW 목은 Refresh 쿠키를 흉내 내지 않고 페이지를 열 때마다 같은 익명 회원(1번)으로 복원한다. 초기화(`DELETE /api/members/me`)하면 쿠키가 지워진 것처럼 다음 로그인에서 회원 번호를 하나 올린다.

## 랜딩

`/landing`은 데스크탑(1024px 이상)과 휴대폰 화면을 `useIsDesktop`으로 나눠 그린다. 문구와 데이터는 `model/landingContent.ts` 한 곳에 둔다.

1. 첫 화면: 제목(자취할 동네를 찾고, 본 방은 기록하고 비교해요), App Store와 Google Play 배지, 웹에서 바로 시작하기(`/`, 쿼리 유지), 소개 영상
2. 기능 다섯 섹션: 동네 찾기, 한 끼 값, 본 방 기록, 체크리스트, 방 비교. 제목 위에 서비스 메뉴 이름(동네 찾기, 저렴한 한 끼, 본 방 기록, 체크리스트, 방 비교)을 두고, 제목 왼쪽 색 막대로 동네 쪽(파랑)과 기록 쪽(노랑)을 나누고, 실제 화면 캡처를 둔다. 휴대폰은 휴대폰 캡처를 쓴다.
3. 왜 만들었냐면: 카드 세 장
4. 속도랑 정확도: 빠르게, 꾸준하게, 정확하게 세 묶음. 왼쪽에 사용자에게 하는 약속과 숫자, 오른쪽에 기술과 시험 조건을 둔다. 격자 그림은 처음부터 완성된 상태로 보이고, 화면에 들어오면 한 번 다시 칠한다.
5. 마지막 화면: 첫 화면과 같은 다운로드와 웹 바로가기

서비스 안(홈 푸터)에서 들어오면 진입 위치와 돌아갈 주소를 라우터 state로 넘긴다. 이때 웹에서 바로 시작하기 자리에 `서비스로 돌아가기`를 두어 홈(`/`)으로 돌려보낸다. 주소에 쿼리를 붙이지 않아 `$pageview` 경로는 광고 유입과 같은 `/landing`이고, 진입 위치는 `landing_viewed`의 `entry`로 남는다. 앱 안에서 열면 이미 설치했으므로 스토어 배지를 숨긴다.

소개 영상은 `tools/landing-motion`에서 만든다. 기능 섹션과 사용 방법이 함께 쓰는 휴대폰 캡처는 `shared/assets/app-screens`에 둔다. 기록, 체크리스트, 비교 캡처는 MSW 예시 데이터(`npm run dev:mock`)로, 동네 찾기(판교역, 기본 조건)와 저렴한 한 끼 캡처는 dev API 익명 회원으로 찍었다(`DEV_API_PROXY_TARGET`과 `API_BASE_URL`을 dev API로 두고 `npm run dev`). 데스크탑은 1440x900, 휴대폰은 390x844 화면을 2배 밀도로 찍는다. 데스크탑 캡처는 `cwebp -q 85 -m 6 -metadata none`으로 바로 WebP로 만든다. 원본 JPG는 앱 스토어 스크린샷 템플릿(`mobile/store-assets`)이 쓰고, 랜딩은 옆에 둔 WebP 사본을 쓴다. 캡처를 바꾸면 `cwebp -q 85 -m 6 -metadata none <이름>.jpg -o <이름>.webp`로 사본도 다시 만든다. 크기는 3배 밀도 휴대폰에 맞춘 780px를 유지한다.

## 첫 진입과 지도 사용 안내

서비스 전체 흐름은 사용 방법(`/guide`)에서 시나리오 영상으로 소개한다. 기능 선택 화면의 서비스 소개 오버레이는 제거했다. 지도 조작 안내는 유지하며, 동네 탐색은 공개로, 실제 기록 저장은 로그인 후 제공한다. 사용 방법 조회는 `usage_guide_viewed`로 수집한다.

뒤로가기나 같은 탭 새로고침에서는 목적지·필터·선택 동네/정류장 코드를 sessionStorage에 30분 동안 보관해 복원한다. API/목 데이터 설정 및 공개/서비스 경로별로 분리한다. 경계와 API 응답은 저장하지 않고 Query Cache를 재사용하거나 조건으로 다시 조회한다. 다시 선택하기를 누르면 저장 조건도 초기화한다. 저장 정보가 없거나 만료된 상세 주소는 오류 안내 화면 대신 위치 선택 지도로 이동한다.

동네 찾기 지도(공개 `/explore`, 로그인 뒤 `/neighborhoods` 모두)는 위치를 고르기 전까지 화면 아래 띠에 누르는 동작(퍼지는 고리와 눌리는 점) 아이콘과 `지도를 눌러 출퇴근 장소를 찍어보세요` 안내를 띄운다. 지도 위 한 점에 두면 확대·이동해도 화면에 붙어 따라와 마커처럼 보여서, 지도와 무관한 화면 아래 자리에 둔다. 처음 온 사람이 지도를 눌러야 하는지 몰라 멈추는 일이 많아, 한 번 보고 닫는 안내가 아니라 위치를 고를 때까지 들어올 때마다 보여 준다. 안내는 지도 클릭을 막지 않으며, 검색어를 입력하거나 필터 시트를 여는 동안에는 숨긴다. 예전에 로그인 뒤 화면에만 띄우던 닫기 가능한 입장 토스트는 이 안내로 대체했다.

위치를 고른 뒤의 단계별 안내(조건 선택 → 찾기 말풍선)는 쓰는 사람이 거의 없어 없앴다. 처음부터 아래에 떠 있는 시트에서 조건 칸을 바꾸고, 위치를 고르면 `{장소 이름}에서 찾기` 버튼을 누른다. 그래서 `exploration_tutorial_viewed`·`skipped`·`completed` 이벤트와 `jachwi.exploration-tutorial.*` 저장 키도 더 이상 쓰지 않는다.

## 전환 이벤트

| 이벤트                           | 발생 기준                                 |
| -------------------------------- | ----------------------------------------- |
| `usage_guide_viewed`             | 사용 방법 진입                            |
| `exploration_started`            | 위치를 정하고 조건으로 찾기를 누름        |
| `exploration_completed`          | 조회 성공, 빈 결과도 결과 개수와 기록     |
| `exploration_record_cta_clicked` | 조회 완료 후 방 기록 버튼 클릭            |
| `exploration_login_completed`    | 자동 로그인으로 바뀌어 지금은 보내지 않음 |
| `exploration_record_form_viewed` | 등록 화면을 지워 지금은 보내지 않음       |
| `exploration_property_saved`     | 등록 화면을 지워 지금은 보내지 않음       |

공개 탐색 이벤트에 `journey_id`, `exploration_mode`, `source: landing`, `mock_data`를 함께 보낸다. 주소·좌표·닉네임은 이벤트에 넣지 않는다. 선택 위치는 로그인 이후 이어가기 위해 현재 탭의 sessionStorage에 보관하고 30분 후 무효화한다. 저장소가 차단되면 기록 전환은 현재 탭 메모리만 사용하며, 지도 재진입 복원은 지원하지 않는다.

PostHog에서는 단순 이벤트 발생 횟수가 아니라 고유 방문자 기반 퍼널로 본다. `mock_data: true`는 운영 지표에서 제외한다.

- 기능 사용 전환율: 랜딩 방문자 중 `exploration_started` 방문자 비율.
- 기능 완료율: 탐색 시작 방문자 중 `exploration_completed` 방문자 비율. 빈 결과는 `result_count`로 별도 구분.
- 서비스 진입 전환율: 탐색 완료 방문자 중 `exploration_record_form_viewed` 방문자 비율.
- 기록 저장 전환율: 탐색 완료 방문자 중 `exploration_property_saved` 방문자 비율.

로그인은 전환의 중간 단계이며, 버튼 클릭이나 폼 진입을 실제 기록 저장으로 집계하지 않는다. 로그인 후 등록 폼으로 자동 이동하지 않으므로 `exploration_record_form_viewed`와 `exploration_property_saved`는 현재 흐름에서 발생하지 않는다. 대시보드/퍼널 설정은 별도이며 이 시안은 이벤트 발생 지점만 제공한다.
